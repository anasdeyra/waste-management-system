# WasteMS — Frontend

React single-page application of the Intelligent Waste Management System.

| Technology | Version | Purpose |
|---|---|---|
| React | 19 | UI runtime |
| TypeScript | 5.x / 7.x | typed application code |
| Vite | 8.x | dev server and build |
| Tailwind CSS | 4.x | styling |
| shadcn/ui | latest | component library (Radix UI primitives) |
| TanStack Query | 5.x | server state and caching |
| React Router | 7.x | client-side routing |
| lucide-react | 1.x | icons |

## Getting started

```bash
npm install
npm run dev
```

The dev server listens on <http://localhost:5173> and proxies every `/api` request to the
Spring Boot backend on <http://localhost:8080>. Start the backend first — see the
[repository README](../README.md).

## Scripts

| Script | Purpose |
|---|---|
| `npm run dev` | development server with hot reload |
| `npm run build` | type-check (`tsc -b`) and build to `dist/` |
| `npm run preview` | serve the production build locally |
| `npm run lint` | run the linter (oxlint) |

## Project layout

```
src/
├── components/
│   ├── ui/          # shadcn/ui components — vendored, do not hand-edit
│   ├── layout/      # application shell, page header, stat cards
│   └── shared/      # reusable widgets (data table)
├── hooks/           # React contexts and hooks (authentication)
├── lib/             # API client, formatters
├── pages/           # one page per functional area
├── types/           # TypeScript mirror of the backend API contract
├── App.tsx          # routes and the authentication guard
└── main.tsx         # providers: Query, Router, Auth
```

## Conventions

- Server state is read through TanStack Query; there is no hand-written `useEffect` fetch.
- The API contract lives in `src/types/api.ts` and must match the backend records.
- `@/` is the path alias for `src/` (configured in `vite.config.ts` and `tsconfig.app.json`).
- Components under `src/components/ui/` are generated by the shadcn CLI and are **not**
  counted as own code in the Part 6 metrics.
