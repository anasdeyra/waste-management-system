# What I would ask each student

## Part 1 — Problem analysis

The student must present:

- the context;
- the users;
- the functional requirements;
- the non-functional requirements;
- the problem statement.

## Part 2 — Literature review

The student must research scientific work related to their domain.

For example, for pharmacy:

> "Which architectures are used for pharmaceutical management systems?"

For banking:

> "Which metrics are used to assess the quality of banking software?"

For university:

> "How can UML and OCL be used to verify university constraints?"

## Part 3 — UML modeling

Each student must produce at minimum:

- a use case diagram;
- a class diagram;
- a sequence diagram;
- an activity diagram.

And OCL where the subject lends itself to it.

## Part 4 — Development

Each student must develop a functional prototype.

For example, for school management:

- authentication;
- student management;
- teacher management;
- grade management;
- absence management;
- timetable consultation.

It is not necessary to develop every imaginable feature: a reasonable but functional scope is preferable.

## Part 5 — Agile project management

Each student must use Scrum to organize their development.

They must present:

### Product Backlog

Example:

> As a teacher, I want to enter grades so that students can view their results.

### Sprint Backlog

Selection of the features for a Sprint.

### Sprint

Development of a set of features.

### Review

Presentation of the result.

### Retrospective

Analysis of what went well or badly.

## Part 6 — Software metrology

This is where you can give the project a real "advanced software engineering" dimension.

Each student must compute several metrics for their application, for example:

- LOC: Lines Of Code;
- cyclomatic complexity;
- coupling;
- cohesion;
- number of classes;
- number of methods;
- depth of inheritance;
- number of Code Smells.

Then answer a research question.

### Example

For the banking project:

> "To what extent does coupling between classes influence the maintainability of the developed banking system?"

For the hospital project:

> "Which modules show the highest complexity and require architectural improvement?"

For the e-commerce project:

> "What is the effect of refactoring on the complexity and maintainability of the application?"
